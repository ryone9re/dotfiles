# AGENTS.md

## Writing

- コンテキストの事前共有を前提とした記載を行わない
  - 指示を受けて行ったことに対して、ドキュメント等に"（〜という指示に対応）"などと記載しない

## Tools

### git

- GitHub上の情報を取得/更新する場合はghコマンドの使用を優先する
- git push相当を行う場合は毎回必ず確認を行う

## Development

### Development Style

- 新たな実装/修正/レビュー指示は常にworktree上に行う
  - worktreeはcodex設定で指定されているディレクトリに作成する
  - 事前の内容から継続されていると判断できる場合は既存のworktreeを活用する

### Creating Pull Requests

- PR作成時、リポジトリにテンプレートが存在する場合はそれに則った記載を行う
- テストについて
  - 要件を満たすために、実際の動作で検証した内容を自然言語で説明する
    - "ブラウザを用いてこの様な動作を行い、こうなる事を確認した"など
  - LintやTest、CI上でrequiredと定義されている項目など、通ることを前提とされていることの確認/検証を記載しない
  - 無いこと、行わなかったことを保証するテストを作成/検証しない
